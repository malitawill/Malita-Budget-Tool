# Malita-Budget-Tool

The Malita Budget Tool is a tool that is designed to fit personal budget needs.

### Why this tool was created:
I have a specific way I like to budget and the budgeting tools I have seen or tried don't fit. Since I am a software developer, I decided I could take matters into my own hands and make a software tool that helps me keep track of my budgeting instead of manually entering things into a spreadsheet and having a harder time keeping track of it.
